# Подготовка данных, обучение и оценка

Здесь находятся реализации методов и код запуска экспериментов. Происхождение исходных файлов и SHA256 записаны в `configs/engine_sources.json`.

- `reproduce.py` запускает цепочку глав 01–06 через `ResearchSession` в режиме `train`.
- `best_models.py` запускает общее сравнение главы 07 через `BestModelStudy`.
- `recsys_lab/` содержит общие реализации данных, моделей, рекомендаций и метрик.

Оба пути работают в отдельном каталоге `local_runs/<RUN_NAME>/engine/`. Порядок этапов и настройки задаются в ноутбуках.
