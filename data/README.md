# Данные T-ECD

[T-ECD Small / Marketplace](https://huggingface.co/datasets/t-tech/T-ECD), revision
`79bcf78cd4699267f561ad3fd51fe7b52af53083`.

Для просмотра выполненных ноутбуков исходные события и модели не нужны.
Для обучения в главах 01–06 (`train`) или главе 07 скачайте данные:

```bash
python -m pip install -e '.[training]'
python tools/download_data.py --destination /path/to/tecd-marketplace
```

Команда получает `items.pq`, события 1174–1299 и 1301–1307. Дни 1301–1307
читаются при финальной оценке; пропускаемый день 1300 не используется. Условия доступа и
использования указаны на странице датасета. Загрузчик сохраняет revision,
размеры и SHA256 полученных файлов. Неизвестные существующие файлы не заменяет.

Можно самостоятельно скачать те же файлы из указанной версии. В notebook задайте
`RAW_DIR`, содержащий `items.pq` и папку `events` с именами вроде `01202.pq`.
В главе 07 путь также можно задать переменной окружения `T_ECD_RAW`.
Рядом с сырыми файлами не записываются модели: все вычисляемые данные находятся
в `local_runs/<RUN_NAME>`. Данные, веса и большие выдачи в Git не добавляются.
