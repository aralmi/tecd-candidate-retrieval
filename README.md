# Отбор кандидатов для персональных рекомендаций

Рекомендательная система может выбирать из миллиона товаров. Чтобы дальше сортировать только небольшой список, сначала отбираем 200 кандидатов для каждого пользователя. По событиям T-ECD Marketplace проверяем, сколько товаров, по которым пользователь кликнул на следующей неделе, попало в этот список.

Главный вопрос работы — помогают ли обучаемые модели находить больше товаров, по которым пользователь кликнет, чем простые правила. Начинаем с общего списка популярных товаров. Затем проверяем личную частоту: сначала берём товары, с которыми пользователь чаще взаимодействовал, и заполняем оставшиеся места популярными товарами. С этим правилом сравниваем BM25, ALS, поиск по готовым векторам, двухбашенную и последовательную модели. Отдельно проверяем, какие модели полезны в общем списке из 200 мест.

На неделе настройки личная частота оказалась лучшим отдельным методом по полноте. Наибольшую полноту среди объединений дала личная частота с глобальной популярностью за 90 дней. Для отложенной проверки заранее выбрали другой вариант с ALS: он немного повысил полноту, но снизил NDCG, который учитывает позиции попаданий в списке.

## Сводное сравнение на 1293–1299

Сравниваем методы на одних пользователях и одном каталоге. Если пользователь кликнул по четырём доступным товарам, а список нашёл один, его Recall@200 равен 1/4. В таблице показано среднее по пользователям. NDCG@200 даёт больше веса попаданиям в начале списка. На этой неделе выбирались настройки.

| Метод или объединение | Recall@200 | NDCG@200 |
| --- | ---: | ---: |
| Популярные товары за 28 дней (`pop28`) | 0,2726 | 0,1137 |
| Личная частота с популярным добором (`personal_pop28`) | 0,2950 | 0,1127 |
| BM25 | 0,0602 | 0,0218 |
| ALS | 0,2583 | 0,0819 |
| Поиск по готовым векторам | 0,0241 | 0,0127 |
| Двухбашенная модель | 0,2811 | 0,0920 |
| Последовательная модель | 0,2715 | 0,1012 |
| Личная частота + ALS + две башни | 0,3206 | 0,1170 |
| Личная частота + все пять моделей | 0,3182 | 0,1144 |
| Личная частота + популярность за 90 дней | **0,3261** | 0,1130 |
| Личная частота + популярность среди целевых товаров обучения | 0,3242 | **0,1312** |

Личная история повысила Recall с 0,2726 до 0,2950 относительно общего топа за 28 дней. NDCG немного снизился, с 0,1137 до 0,1127. Объединение с популярностью за 90 дней дало наибольший Recall на этой неделе и уступило личной частоте на двух более ранних. ## Отложенная проверка на 1301–1307

До оценки выбрали два варианта для сравнения. Первый использует личную частоту с добором. Во втором 10 из 200 мест отданы ALS, который ищет товары по сходству взаимодействий пользователей. Добавление ALS повысило Recall с **0,1955 до 0,1972**, или на **0,172 п. п.** Парный 95% интервал прироста составляет от +0,057 до +0,298 п. п. NDCG снизился с **0,0684 до 0,0658**. ## Данные и оценка

Исходная выборка содержит 80 018 пользователей и 19,8 млн событий. На неделе 1293–1299 у 4 335 пользователей были клики, из них у 4 319 был хотя бы один клик по товару из доступного каталога. Recall@200 в главной таблице усредняется по этим 4 319 пользователям. В каталоге на эту неделю 1 060 869 товаров. Номера 1293 и 1301 обозначают дни датасета. Между доступной историей и неделей проверки пропускается один день.

`personal_pop28` использует личную частоту за 60 дней и добор популярностью за 28 дней. `raw` в оценках нейросетей означает расчёт сходства без поправки на популярность. Популярный добор применяется отдельно, если в списке меньше 200 товаров. [Определения метрик и ограничения оценки](research/01_data_and_protocol/README.md)
