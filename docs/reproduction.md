# Запуск исследования

## Просмотр результатов

Все восемь ноутбуков содержат сохранённые таблицы и графики. Их можно открыть на GitHub или в Jupyter. Для обучения нейросетей требуется Apple MPS.

В главах 01–06 и приложении MPS по умолчанию выбран `MODE = "saved"`. Повторный Run All читает таблицы прежних экспериментов и строит графики. В главе 07 другой порядок: Run All выполняет подготовку, обучение и оценку. При том же `RUN_NAME` завершённые этапы используются повторно.

Для работы с сохранёнными результатами:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

Откройте нужный ноутбук в VS Code или Jupyter и выберите это окружение. `tools/execute_saved_notebooks.py` выполняет только главы 01–06 и приложение; главу 07 пропускает. Его локальный отчёт `results/demo_execution.json` в Git не входит.

## Данные и зависимости для обучения

```bash
python -m pip install -e '.[training]'
python tools/download_data.py --destination /path/to/tecd-marketplace
```

Используется T-ECD Small / Marketplace, revision `79bcf78cd4699267f561ad3fd51fe7b52af53083`. Загрузка выполняется отдельной командой. Можно использовать уже скачанный каталог с `items.pq` и `events/`; структура описана в [инструкции по данным](../data/README.md).

## Главы 01–06: основная цепочка исследования

В настройках каждого из шести ноутбуков:

```python
MODE = "train"
RUN_NAME = "reproduction"
RAW_DIR = "/path/to/tecd-marketplace"
```

Выполните главы по порядку с одним `RUN_NAME`. Расчёты сохраняются в `local_runs/<RUN_NAME>/engine/`. Завершённый этап используется повторно. Для отдельного обучения выберите другое имя запуска. При смене кода, конфигурации или входных файлов прежний запуск не перезаписывается.

| Глава | Вычисления из сырых данных |
| --- | --- |
| 01 | Отбор когорты по strong-действиям за 1202–1261, подготовка событий, каталога и векторов |
| 02 | Популярность, недавние товары, личная частота, готовые векторы, ALS, BM25 с 300 соседями; полный профиль ALS при тех же товарных факторах |
| 03 | Недельные обучающие пары за 4 и 8 недель; две двухбашенные модели с остаточной связью, бюджетом до 4000 обновлений и 256 негативами |
| 04 | Префиксы до 100 событий; усреднение истории и последовательный энкодер используют последние 50, по 6000 обновлений |
| 05 | Три периода и три seed ALS; квоты 10/25, добавленные и потерянные цели, парный bootstrap |
| 06 | Зафиксированные personal и ALS10 на 1301–1307; рекомендации, Recall, NDCG и парный bootstrap |

`engine/reproduce.py` связывает эти этапы. `src/recsys_lab/session.py` выбирает сохранённые или вычисленные результаты. Таблицы и графики строятся одним кодом в обоих режимах.

## Глава 07: общее сравнение пяти моделей

[Ноутбук](../research/07_best_models/analysis.ipynb) запускается отдельно от цепочки 01–06. В нём заданы общие пользователи, каталог и неделя оценки 1293–1299. Настройки находятся в `configs/best_models.json`.

1. Задайте `T_ECD_RAW` — путь к сырым данным; по умолчанию используется `data/raw`.
2. Для нового обучения измените `RUN_NAME` в первой ячейке.
3. Выполните ячейки по порядку: данные → классические методы → две башни → последовательная модель → объединения и графики.

Необязательный `RECSYS_PREPARED_STUDY` указывает на каталог прежних подготовленных данных. Без него ячейка подготовки строит входы из сырых файлов. Кеш используется только для входных данных: прежние веса и выдачи из него не загружаются.

Последний общий запуск полностью выполнен: модели обучены заново, затем рассчитаны рекомендации, метрики и объединения. Подготовленные входы взяты из кеша. Путь подготовки этой главы без кеша в данном запуске не выполнялся.

Рабочие файлы и полные журналы этапов сохраняются в `local_runs/<RUN_NAME>/engine/bench_results/`. В ноутбуке показаны статусы, итоговые таблицы и графики. Последняя ячейка копирует компактные результаты в `research/07_best_models/results/`; графики лежат в `figures/` этой главы. При повторном использовании завершённого этапа обучение не повторяется.

## Дополнительные исторические проверки

Основная цепочка не повторяет все прежние эксперименты с температурой, функциями потерь, расширением популяции, CCL и численным аудитом. В режиме `train` таблицы таких опытов помечаются как исторические, если они не вычислены в текущем запуске.

Их параметры находятся в `configs/experiment_history.json`, оценки — в `results/metric_index.csv`. Общий запуск описан отдельно в главе 07.

## Окружение

Обучение нейросетей в этих рецептах требует MPS; переход на CPU отключён. Классические методы работают на CPU. Среда запусков: Python 3.12, PyTorch 2.9.1, Apple M2 Air с 16 ГБ памяти. Версии пакетов перечислены в `environment_reference.json`.

Сырые данные, веса, подготовленные массивы и большие выдачи не входят в Git. Финальная неделя 1301–1307 уже использована: её повтор воспроизводит прежний рецепт, без подбора новых параметров по финальным целям.
